# To-DoX 2.3.0-dev.1

Préversion de développement intégrant les modifications locales actuelles de l'interface.

- En-tête Kanban réorganisé, ajustements de mise en forme et de navigation.
- Améliorations des libellés accessibles, du focus des menus et du respect des préférences de réduction des animations.
- Ajustements de l'installateur Windows et de l'option de démarrage automatique.
- Canal dev installé sur demande depuis CEA Appstore ; les mises à jour intégrées sont désactivées dans cette préversion.

## Installation

Télécharger l'installateur Windows de cette release, ou choisir **Options avancées → Développement** dans CEA Appstore puis installer explicitement cette version. Sauvegarder les données avant de remplacer l'installation courante. La version dev utilise le même emplacement de données que la stable.

Cette release doit rester marquée **Pre-release**, sans devenir **Latest**. La v2.2.2 stable ne la propose pas comme mise à jour. Le manifeste du catalogue conserve sa référence stable pour les anciens Appstores.

## Validation

- Build TypeScript/Vite réussi.
- 54 tests Vitest réussis.
- Test du moteur electron-updater 6.7.3 utilisé par la v2.2.2 : une release dev plus récente est ignorée ; seul le fichier de mise à jour de la stable est consulté.
- Lint : 51 erreurs et 23 avertissements signalés dans le dépôt ; cette préversion ne constitue pas une remise à niveau générale du lint.
